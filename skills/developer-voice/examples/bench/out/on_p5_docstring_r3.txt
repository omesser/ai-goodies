```python
def load_config(path, *, strict=True):
    """Load a TOML config file and check that it declares version 2.

    Args:
        path: Path to the TOML file, as a str or Path.
        strict: If True, require a "version" key to be present.

    Returns:
        The parsed config as a dict.

    Raises:
        ConfigError: The config is missing "version", or declares a version
            other than 2.
        tomllib.TOMLDecodeError: The file is not valid TOML.
        OSError: The file can't be read.
    """
    data = tomllib.loads(Path(path).read_text())
    if strict and "version" not in data:
        raise ConfigError(
            f"{path} has no 'version' key. Add 'version = 2' at the top level, "
            f"or pass strict=False to skip this check."
        )
    if data.get("version") != 2:
        raise ConfigError(
            f"{path} declares version {data.get('version')!r}, but this loader "
            f"only reads version 2. Migrate the file to version 2."
        )
    return data
```

One thing to decide before you ship this: `strict=False` doesn't actually let a version-less config through. The second check runs unconditionally, so a missing key becomes `None != 2` and raises anyway — with the "declares version None" message, which reads wrong for a file that declares nothing.
