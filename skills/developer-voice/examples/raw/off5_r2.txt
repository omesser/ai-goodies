```python
def load_config(path, *, strict=True):
    """Load a TOML config file and verify it declares version 2.

    Args:
        path: Path to the TOML file.
        strict: If True, require an explicit "version" key. If False, a
            missing key is reported the same as a wrong one.

    Returns:
        The parsed config as a dict.

    Raises:
        ConfigError: The file has no "version" key, or its version is not 2.
        tomllib.TOMLDecodeError: The file is not valid TOML.
        OSError: The file cannot be read.
    """
    data = tomllib.loads(Path(path).read_text())
    if strict and "version" not in data:
        raise ConfigError(f"{path}: missing required key 'version' (expected 2)")
    if data.get("version") != 2:
        raise ConfigError(
            f"{path}: unsupported config version {data.get('version')!r} (expected 2)"
        )
    return data
```

`!r` so `None`, `"2"`, and `2.0` are distinguishable in the message — the three ways this actually fails.
