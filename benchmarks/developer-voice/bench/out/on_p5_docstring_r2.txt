```python
def load_config(path, *, strict=True):
    """Load a TOML config file and check that it declares version 2.

    Args:
        path: Path to the TOML file.
        strict: If True, missing `version` is reported as a missing key.
            Otherwise it falls through to the version check. Either way,
            version 2 is required.

    Returns:
        The parsed config as a dict.

    Raises:
        ConfigError: The file omits `version`, or declares a version other than 2.
    """
    data = tomllib.loads(Path(path).read_text())
    if strict and "version" not in data:
        raise ConfigError(
            f"{path}: no `version` key. Add `version = 2` at the top level."
        )
    if data.get("version") != 2:
        raise ConfigError(
            f"{path}: unsupported config version {data.get('version')!r}. "
            f"This build reads version 2 only."
        )
    return data
```

One thing the docstring had to work around: `strict=False` doesn't actually let a version-less config through. The second check sees `None != 2` and raises anyway, so the flag only changes which message you get. If the intent was for non-strict mode to accept unversioned files, the second check needs to be `if "version" in data and data["version"] != 2`.
